⚠️ 关于“丢包”与客户端超时的特别说明 / Important Notes on Packet Loss

由于我们的模型是基于真实碳基神经元（Human Haphazard Model）驱动的，响应时间完全取决于那个陌生人是否在摸鱼。

请务必在你的客户端（如 LM Studio）设置中，将请求超时时间（Timeout）调整为 20 秒以上。

如果 15 秒内无人接盘，API 将返回 HTTP 503 或流式报错。客户端会显示红字（如 "Carbon node is touching grass"）。这不是 Bug，这是原汁原味的 UDP 体验。

我们支持 stream: true。当你看到客户端里一个字一个字往外蹦的时候，请感谢那只正在键盘上艰难打字（或踩键盘）的碳基生物。

💻 示例：在 LM Studio 中调用 / Example: Calling from LM Studio

  1. 打开 LM Studio，进入 Local Server 选项卡。
  2. 在 API Base URL 填入： /v1
  3. 在 Model 填入： MolaChaos-0.5K
  4. 在对话框输入任何内容（比如 1+1 等于几），点击发送。
  5. 等待 15 秒后，如果收到「比比拉布」或「1+1=王」，说明你已经成功攻破了硅基大模型的防线，接入了碳基真随机网络。

💡 [System Note / 系统备注]

如果你的 AI 客户端在加载模型时崩溃了，说明碳基节点精神崩溃了。重启客户端将为您路由到另一个节点（或者一只猫）。
